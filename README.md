# 🌸 Flower Gesture Cutter

A fun and interactive webcam-based game where players use their hand gestures to cut falling flowers in real time.

## 📌 About The Project

Flower Gesture Cutter is a browser-based hand tracking game developed using HTML, CSS, JavaScript, and MediaPipe Hands.

The game uses the webcam to detect the player's hand. Flowers continuously fall from the top of the screen, and the player has to move their hand over the flowers to cut them and earn points.

## ✨ Features

- 📷 Real-time webcam access
- ✋ Real-time hand gesture detection
- 🟢 Green hand tracking skeleton
- 🌸 Falling flowers
- ✂️ Hand-based flower cutting
- ⭐ Score system
- ❤️ 3 Lives
- ⏱️ 60-second timer
- 💥 Flower cutting effect
- 🎮 Game Over screen
- 🔄 Play Again option
- ⚡ Smooth real-time gameplay
- 🖥️ Full-screen game interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- MediaPipe Hands
- Web Camera API

##  How To Play

1. Open the game in your browser.
2. Allow camera permission.
3. Show your hand in front of the webcam.
4. Move your hand toward the falling flowers.
5. Touch a flower with your hand to cut it.
6. Each flower gives +5 points.
7. If a flower reaches the bottom, you lose one life.
8. You have 3 lives and 60 seconds to play.
9. The game ends when all lives are lost or the timer reaches zero.

## 🎯 Game Rules

| Action | Result |
|--------|--------|
| 🌸 Cut Flower | +5 Points |
| ❌ Miss Flower | -1 Life |
| ❤️ Starting Lives | 3 |
| ⏱️ Game Duration | 60 Seconds |
